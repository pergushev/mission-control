# Mission Control

Модуль управления полётными заданиями (миссиями) для беспилотных авиационных систем (БАС) на базе протокола **MAVLink Mission Protocol**.

Позволяет:
- загружать, выгружать и очищать миссии с автопилота (ArduPilot, PX4 и др.),
- создавать миссии с взлётом, путевыми точками и посадкой,
- верифицировать целостность загруженной миссии.

## Состав

- `mission_control.py` — ядро модуля: работа с миссиями через MAVLink.
- `main.py` — интерактивный демо-скрипт для тестирования.

## Требования

- Python 3.7+
- [`pymavlink`](https://pypi.org/project/pymavlink/)

Установка зависимостей:
```bash
pip install pymavlink
```

## Использование

1. Запустите симулятор (например, ArduPilot SITL):
   ```bash
   sim_vehicle.py -v ArduCopter --console --map
   ```
   
2. Запустите демо-скрипт:
   ```bash
   python main.py
   ```
3. Следуйте инструкциям в терминале.
   > Поддерживает подключение по TCP, UDP или последовательному порту.
